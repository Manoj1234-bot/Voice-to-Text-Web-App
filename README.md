# 🎙️ Voice to Text Converter

A modern and responsive **Voice to Text Converter** built using **HTML, CSS, and JavaScript**. This application uses the **Web Speech API** to convert spoken words into text in real time. It supports multiple languages, live speech recognition, word and character counting, text copying, downloading transcripts as `.txt` files, and clearing the transcript with a simple and user-friendly interface.

# ⚙️ How It Works

1. Select your preferred language from the dropdown menu.
2. Click the **Start Listening** button.
3. Allow microphone access when prompted by the browser.
4. Speak into your microphone.
5. Your speech is converted into text in real time.
6. The application automatically updates the word and character count.
7. Copy the transcript, download it as a `.txt` file, or clear it when needed.
